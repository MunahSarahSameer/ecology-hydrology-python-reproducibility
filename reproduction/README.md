This audit inventories candidate evidence files for 15 cases.

The counts are based on filenames only. They do not establish
that complete dependency specifications, executable commands,
original datasets or independently repeatable workflows exist.

`independent_execution_verified = NOT_ASSESSED` applies to
every case in this inventory.

Refer to the DOI/source register, provenance corrections and
case-level execution evidence before attempting replication.

Do not infer successful scientific-result reproduction from
component-level tests or process exit codes.

Some case evidence has redacted local Windows paths.
These are historical records, not directly runnable commands.

This inventory does not constitute a complete reproduction
package for all 15 cases.
